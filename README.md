# ダウンローダー（Android）

Web上でストリーミング再生できる動画のうち、**保護のかかっていないもの**を保存するためのAndroidアプリです。
アプリ内ブラウザでページを開いて動画を再生すると、読み込まれた動画のURLを検出して保存できます。

## できること

- アプリ内ブラウザでページを開き、MP4などの動画ファイル・HLS（m3u8）を自動検出
- MP4などの単体ファイルを保存（途中から再開できます）
- HLSを分割ファイルごとにダウンロードし、1本のMP4に結合（再エンコードなし・画質そのまま）
  - 画質（解像度）を選択できます
  - 映像と音声が別配信の場合も1本にまとめます
- ログインが必要なサイトでも、アプリ内ブラウザでログインすれば、ご自身が見られる動画を扱えます
- 一時停止・再開・再試行、バックグラウンドでのダウンロード、完了通知
- 保存先：既定は端末の `Download/Downloader`。メニューから任意のフォルダに変更できます
- 他のアプリから「共有」でページのURLを送って開けます

## 対応しないもの

- DRMで保護された配信（Netflix・Amazonプライムなどの有料配信）
- 暗号化されたHLS
- YouTubeのように、署名の解読が必要なサイト専用の処理
- 配信中のライブ（終了したアーカイブは対応）
- DASH（mpd）※今後対応予定

## 使い方

1. 上部のアドレス欄にURLか検索ワードを入れてページを開きます
2. 動画を再生すると、右下に「動画 ○件」のボタンが出ます
3. ボタンをタップして保存したい動画を選び、ファイル名を決めて保存します
4. 進み具合はメニューの「ダウンロード一覧」で確認できます

## 注意

保存してよいのは、ご自身の動画や、保存が許可されている動画です。
違法にアップロードされたものと知りながら動画を保存することは、著作権法で禁止されています。
各サイトの利用規約にも従ってください。

## ビルド

`main` ブランチにpushすると、GitHub Actionsが自動でAPKをビルドし、
[Releases](../../releases) に `downloader-v番号.apk` として公開します。スマホからそのままダウンロードしてインストールできます。

- 署名：リポジトリ内の固定鍵（`app/shared-debug.keystore`）で署名するため、新しい版を上書きインストールできます
- より安全にしたい場合は、Secrets に `KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD` を設定すると、そちらの鍵で署名します（鍵を変えた初回だけアンインストールが必要です）

## 構成

| ファイル | 役割 |
| --- | --- |
| `ui/MainActivity.kt` | アプリ内ブラウザ、動画の検出、画質選択 |
| `ui/DownloadsActivity.kt` | ダウンロード一覧 |
| `detect/MediaDetector.kt` | URLから動画かどうかを判定 |
| `hls/HlsParser.kt` | m3u8の解析（暗号化・ライブの判定を含む） |
| `download/FileDownloader.kt` | 単体ファイルのダウンロード（途中再開対応） |
| `download/HlsDownloader.kt` | HLSの並列ダウンロードと結合 |
| `download/Remuxer.kt` | 再エンコードなしでMP4に詰め替え |
| `download/Exporter.kt` | 保存先への書き出し |
| `download/DownloadRepository.kt` | 一覧管理・実行制御 |
| `download/DownloadService.kt` | バックグラウンド実行と通知 |
